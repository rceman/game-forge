# game-forge

Open-source game development harness for deterministic simulation, browser testing, visual validation, GPU benchmarking, and reusable tooling.

Game Forge is intended to provide the reusable engineering environment around games without owning game-specific mechanics or forcing projects onto one engine/runtime.

## Project direction

- [Vision](docs/VISION.md) — complete product direction and system boundary.
- [Architecture](docs/ARCHITECTURE.md) — contract, providers, browser/runtime, resource ownership, scheduler, and first vertical slice.
- [Design Principles](docs/DESIGN_PRINCIPLES.md) — reusable-tooling and asset-pipeline principles, including audio/texture direction.
- [Roadmap](docs/ROADMAP.md) — incremental extraction plan driven by real game consumers.

Spin Tower (`rceman/td-game`) is the first real integration consumer.
